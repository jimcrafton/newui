Live shape handles

A single selected Star, Polygon or Rounded Rectangle (drawn with the shape tools, or loaded from a file - the shape is recognised from its outline) shows extra handles with the Select tool. Dragging one changes the shape itself, as one undo step; the ordinary frame handles still move, resize and rotate it. Resizing a shape unevenly stops it being regular, and the extra handles then go away until it is regular again.

Details

  • The cursor over a live handle is the move cursor; while dragging, a small label shows the value (as drawn above).
  • Handles only show when exactly one such shape is selected and it is not locked. Shift-click or a marquee that selects several shapes hides them.
  • Each change is one undo step ("Change Star Points", "Change Inner Radius", "Change Polygon Sides", "Change Corner Radius").
  • Nothing extra is stored in the file: the shape is recognised from its outline when it is selected, so files from before this change and other programs' regular polygons / stars work too.
